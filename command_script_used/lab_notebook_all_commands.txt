## NOTE ON TOGA MUTATION CALLING (from Hiller lab correspondence)
# Mutations that appear close to C and N termini (more precisely, first and last 10% of the CDS in
# TOGA) are not treated as inactivating because these regions are under weaker evolutionary
# constraints. Inactivations in these regions are very unlikely to kill the gene.
# Lack of the start codon in the expected position also provides very weak evidence for gene
# inactivation. It could be shifted up or downstream. Technically, TOGA detects this sort of mutation
# but doesn't use it for classification.
